# Bàn giao riêng gói DBMS12
1. Nhóm chỉ cần source ZIP này để hiểu và build bản12 hiện tại.
2. Agent đọc AGENTS và chín memory theo thứ tự, rồi requirements/context map.
3. REQUIREMENTS chốt chức năng, toolchain, SQL/Windows/TLS và nghiệm thu máy nhận.
4. SETUP_WINDOWS phân biệt build source với chạy đủ ứng dụng.
5. Owner giữ CLIXML và provision; runtime non-admin chạy host; SQL service đọc cert SQL.
6. SQL TLS khác web HTTPS; cert web/private key phải nằm trong profile runtime.
7. Mỗi máy tạo account/cert/credential/sample riêng, không copy .local hoặc DPAPI.
8. Ví dụ config của tác giả cần đổi trước provision; không tìm prerequisite trong project cha.
9. Memory trỏ source/manifest/API/evidence, không chép lại tất cả SQL.
10. Word/PDF rubric không kèm, chưa chứng minh đạt toàn đề hoặc nghiệm thu máy thứ hai.
11. Lượt này chỉ sửa tài liệu/hash/source ZIP, không đổi code/SQL/runtime/DB/ACL.
